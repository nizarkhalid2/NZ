# MyOS — GitHub Pages build

This folder is prepared from the exported Framer site for static hosting on GitHub Pages.

## Publish
1. Create a GitHub repository.
2. Upload **all files and folders in this ZIP to the repository root** (do not upload the outer ZIP folder as a nested folder).
3. Commit the files.
4. In GitHub: **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Branch: **main** / folder: **/(root)** → **Save**.
7. Wait for GitHub Pages to publish the site.

The Framer JavaScript bundles, motion runtime, images, videos, fonts, CMS export files, and interactions included in the export are kept in this build.

## Important
This is a static export of the published site, not the editable Framer project source. Changes should ideally be made in Framer and exported again, or directly in the generated files if you know the bundle structure.
